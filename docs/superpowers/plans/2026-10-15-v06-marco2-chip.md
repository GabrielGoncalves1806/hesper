# v0.6 Marco 2 · Chip e máquinas na rede · Plano de implementação

> **Para agentes:** SUB-SKILL: superpowers:executing-plans (inline) ou superpowers:subagent-driven-development. Passos em checkbox (`- [ ]`).
> **Neste projeto agentes NÃO commitam**: cada tarefa termina com `uv run pytest` verde; quem commita é o gerente.

**Objetivo:** drill, derretedor e dispersor ganham um slot de chip. Sem chip, a máquina fica fora da rede dos drones; com chip, aparece a seção DRONES. O derretedor passa a receber gelo e o dispersor a receber cápsula, sempre no slot daquele item. O chip ganha receita na Bancada T2 e o save sobe pra v11. De brinde (pedido do dono), o estado do dispersor no mundo só aparece com o mouse em cima; parado por problema, ele mostra um "!".

**Arquitetura:** `Machine.chip: bool` (sem inventário próprio: é 0 ou 1). A rede dos drones continua sendo a lista que o `GameState.drone_logistics()` passa pro `drones.update_stations`. O filtro do chip entra **só ali** (`Machine.in_network`), então `drones.pick_task`/`Ledger` e os testes que chamam o `drones.py` direto com uma lista não mudam. Os drones já tratam máquina que sumiu da lista: a origem que sai faz o drone voltar vazio, e o destino que sai faz ele procurar outro. Quem recebe num slot fixo (entrada de gelo, slot de cápsula) passa por `drones.receive_slot` / `drones.deliver`, e o `Ledger.room` olha o espaço daquele slot.

**Stack:** Python 3.13, pygame-ce, uv, pytest.

**Spec:** `docs/superpowers/specs/2026-10-15-v06-logistica-design.md` (Marco 2). Bíblia §14.

## Restrições globais
- Precisam de chip: `drill`, `melter`, `melter_t2`, `o2_dispenser` (`Machine.needs_chip`). **Baú não precisa** de chip e continua sempre na rede.
- O slot aceita só o item `chip`, 1 por máquina. O chip é um item de loot (`C.LOOT_ITEMS`, empilha 20) e continua saindo de loot.
- O que cada máquina aceita:

| Máquina | Envia | Recebe (padrão ao entrar o chip) | Slot que recebe |
|---|---|---|---|
| Drill | o minério dela | nada | — |
| Derretedor (nv.1 e nv.2) | `water_capsule` | `ice` | `C.MELTER_ICE_SLOT` |
| Dispersor de O₂ | nada | `water_capsule` | `C.DISPENSER_CAPSULE_SLOT` |
| Baú | qualquer `LOGISTIC_ITEMS` | qualquer (nada por padrão) | o inventário todo |

- Painel sem chip: no lugar das linhas Envia/Recebe/Lote, o texto **"Coloque um chip pra ligar aos drones"**. O slot do chip aparece com chip ou sem chip; vazio, ele usa o sprite aprovado `chip_slot_empty` (16×16, desenhado em (2,2) do slot, com o alpha da própria imagem). Com chip, o slot mostra o ícone `icon_chip`.
- Entrou o chip: os itens que a máquina pode receber entram no `receives`, ou seja, `ice` no derretedor e `water_capsule` no dispersor. O Envia fica como estava.
- Tirou o chip: a máquina sai da rede na hora. O `sends`/`receives`/`batch` ficam guardados pra quando o chip voltar.
- Desmontar devolve o chip junto com a receita e o conteúdo.
- Linha sem item possível não aparece no painel: o dispersor não mostra Envia e a drill não mostra Recebe. O **Lote** só aparece se a máquina pode enviar alguma coisa, porque ele é "quanto o drone tira daqui".
- Receita do chip (Bancada T2, só o inventário): **2 `silicon_wafer` + 1 `iron`**. Na spec isso é o "1 ferro (partida)", e o ferro é o minério (`iron`), não o `iron_ingot`.
- Save **v11**: `SAVE_VERSION = 11`, `FIRST_VERSION` continua 10. A máquina que precisa de chip grava `"chip": bool`. `MIGRATIONS[10]` dá `chip = True` pra drill e derretedor com `sends` não vazio. O dispersor vem sem chip.
- Dispersor no mundo: o rótulo do estado (`C.STATE_LABEL`) só aparece com o mouse em cima, no mesmo esquema do `App.labeled_chests`. Sem hover, estado diferente de `"sealed"` mostra só um selo pequeno "!" na cor do estado (`C.STATE_COLOR`), no lugar onde o rótulo ficaria. Vedado e sem hover não mostra nada.
- UI: nada de UW/UH/HOTBAR fixos em código novo; mouse via `app.mouse_ui`; superfície nova sempre com formato explícito (teste AST existente). Não abrir janela, não commitar, não mexer em `assets/`, `tools/sprites`, `tools/audio`, `reports/design`, `reports/audio`, `saves/`, `settings.json`.
- **Mudou trava, custo, receita ou o que entra na rede: rode as 3 ferramentas** (`uv run pytest`, `uv run python tools/dev/smoke.py`, `uv run python tools/dev/real_video_check.py`). O smoke, o checador de vídeo e o `tools/dev/balance_sim.py` montam drill e derretedor e esperam drone levando coisa. A partir deste marco, essas máquinas precisam de chip.

## Decisões (o dono deveria ver)
- **Chip é `bool`, não um `Inventory(1)`.** Fica mais simples de salvar (a spec pede `chip: bool`), e o slot é tratado à parte no painel (`ui.chip_rects`), igual às baias da estação.
- **Lote some em quem só recebe** (o dispersor), pelo motivo da tabela.
- **Gate do chip só no `drone_logistics()`**: `can_send`/`can_receive`/`toggle_*` não olham o chip. Assim o save carrega a configuração mesmo com a máquina sem chip.
- Por enquanto, encaixar e tirar o chip toca o `ui_click` de hoje. O bip do Som (2.5) entra quando o dono aprovar.

    def chip_install(self, machine: Machine) -> bool:
        """Põe um chip na máquina (v0.6 M2): ela entra na rede e o Recebe dela liga (derretedor: gelo; dispersor:
        cápsula). Não gasta item: quem chama tira o chip de onde ele estava. False se não leva chip ou já tem."""
        if not machine.needs_chip or machine.chip:
            return False
        machine.chip = True
        machine.receives |= {i for i in C.LOGISTIC_ITEMS if drones.can_receive(machine, i)}
        self.events.append(("chip_on", machine.anchor))
        return True

    def chip_install_from(self, machine: Machine, index: int) -> bool:
        """Shift+clique num chip do inventário com o painel da máquina aberto: gasta 1 do slot `index`."""
        stack = self.inventory.slots[index]
        if stack is None or stack.item != "chip" or not self.chip_install(machine):
            return False
        self.inventory.remove_from_slot(index, 1)
        return True

    def chip_take(self, machine: Machine) -> bool:
        """Tira o chip pro inventário: a máquina sai da rede na hora (os drones a caminho seguem as regras de
        origem/destino que somem). Não cabendo, fica nela e avisa."""
        if not machine.chip:
            return False
        if self.inventory.add("chip", 1):
            self.events.append(("inv_full",))
            return False
        machine.chip = False
        self.events.append(("chip_off", machine.anchor))
        return True
```

def can_send(machine, item: str) -> bool:
    """A drill só envia o minério dela, o derretedor só a cápsula, o dispersor nada (v0.6 M2); o baú, qualquer
    item logístico."""
    if item not in C.LOGISTIC_ITEMS or machine.is_dispenser:
        return False
    if machine.is_melter:
        return item == "water_capsule"
    return not machine.is_drill or item == machine.resource


def can_receive(machine, item: str) -> bool:
    """v0.6 M2: o derretedor recebe gelo (na entrada), o dispersor cápsula; a drill nada; o baú, qualquer item."""
    if item not in C.LOGISTIC_ITEMS or machine.is_drill:
        return False
    if machine.is_melter:
        return item == "ice"
    if machine.is_dispenser:
        return item == "water_capsule"
    return True


def receive_slot(machine, item: str) -> int | None:
    """O slot fixo onde esse item entra (derretedor: entrada de gelo; dispersor: o da cápsula), ou None (qualquer)."""
    if machine.is_melter and item == "ice":
        return C.MELTER_ICE_SLOT
    if machine.is_dispenser and item == "water_capsule":
        return C.DISPENSER_CAPSULE_SLOT
    return None


def slot_room(storage, slot: int, item: str) -> int:
    have = storage.slots[slot]
    if have is None:
        return max_stack(item)
    return have.room if have.item == item else 0


def deliver(machine, item: str, amount: int) -> int:
    """Põe `amount` de `item` na máquina (no slot certo). Devolve quanto NÃO coube."""
    slot = receive_slot(machine, item)
    if slot is None:
        return machine.storage.add(item, amount)
    moved = min(amount, slot_room(machine.storage, slot, item))
    if moved:
        have = machine.storage.slots[slot]
        if have is None:
            machine.storage.slots[slot] = Stack(item, moved)
        else:
            have.count += moved
    return amount - moved
```
